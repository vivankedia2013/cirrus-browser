# Changelog

## 1.0.0
- First release of Cirrus.
- Google search with suggestions, tabs, private tabs, bookmarks, history, downloads, find in page, zoom, DevTools.
- Login page and AES-256-GCM encrypted password vault with save prompt, autofill and auto-clearing clipboard.
- Built-in AI tab (Claude, your own API key).
- CPU and RAM limiter with sleeping tabs and a live performance panel.
- 8 backgrounds, custom image, accent colour; auto-lock; session restore; site permission prompts.
- Windows 10/11 and macOS 10.13 to 26.
